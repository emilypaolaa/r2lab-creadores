# R2LAB · Portal para creadores

Página estática (HTML + CSS) para los creadores de TikTok LIVE de R2LAB.

## Cómo actualizar
1. Edita `index.html` (textos y enlaces) o `style.css` (diseño).
2. Guarda y haz commit + push a `main` (o pídeselo a Claude).
3. Vercel publica los cambios solo en 1–2 minutos.
